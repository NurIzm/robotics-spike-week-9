# Роборука

Урок 9 кружка робототехники: манипуляторы и автономия на LEGO SPIKE Prime. Собираем модель «Роборука» и программируем её блоками.

**Открыть урок:** https://nurizm.github.io/robotics-spike-week-9/

## Что внутри

- стартовый экран с 3D-моделью Роборуки;
- урок: что такое манипулятор, степени свободы, виды захватов, из чего состоит модель, сборка и разборка, мини-тест;
- шесть анимированных примеров из жизни: автозавод, склад, хирургия, космос, ферма, спасатели;
- программа: блоки как в приложении SPIKE слева, работающая 3D-модель справа, четыре задания.

Кнопка «Начать заново» на экране программы возвращает стартовую программу и стирает отметки. Она нужна перед следующим классом.

## Без интернета

Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `index.html` двойным кликом. Всё работает, только шрифты будут запасными.

## Как поменять

`index.html` собирается из исходников, вручную его не правьте. Экраны лежат в `src/views`, логика в `js`, стили в `css`, исходное задание в `src/SPEC.md`.

```bash
node src/build.js
```

Логику блоков проверяет `tests/vm-check.html`: откройте его в браузере, все строки должны быть PASS.
